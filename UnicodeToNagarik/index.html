What is Nagarik Regular?

Nagarik Regular is a legacy Nepali font. Unlike Unicode fonts, legacy fonts use character positions and keyboard mappings to represent Nepali characters.

This converter is designed to make it easier to move Nepali text from Unicode-based systems into Nagarik Regular based workflows.
