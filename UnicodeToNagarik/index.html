Unicode to Nagarik Example

A Unicode-to-legacy-font converter must use the character encoding specific to the target font. Nagarik Regular should therefore be converted using its verified Nagarik character mapping rather than substituting a Preeti mapping.

For example, the commonly seen g]kfn representation is associated with the Preeti-style legacy encoding and should not automatically be treated as the Nagarik mapping.

About Nagarik Regular Font

Nagarik Regular is a legacy Nepali TrueType font. Legacy fonts use font-specific character encodings, meaning the underlying text characters may be ordinary ASCII characters while the installed font displays them as Nepali glyphs.

Because of this, accurate conversion depends on the actual Nagarik Regular character map. The converter should not assume that mappings from Preeti, Kantipur or another Nepali legacy font are identical.

Using Nagarik Text in Microsoft Word

After converting the text, copy the output and paste it into Microsoft Word. Select the Nagarik Regular font if it is installed on your computer.

If the characters do not display correctly, check that the correct Nagarik font is installed and selected. Different legacy fonts can use different character mappings.
